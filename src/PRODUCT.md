# Product UI/UX Expectations

As a user, I want visual feedback whenever an action isn't immediate. On list screens (Library, Discover, Queue), I want skeleton loaders that match the shape of the content as those load. For one-time actions like submitting an RSS URL, seeing a loading spinner is fine. When an error occurs, I want a non-blocking toast message with red styling and a red 'X' icon and a plain-language description, not a modal or a crash. Empty lists should show an illustration or icon, a short explanation, and a CTA button to take the next step (e.g. "No podcasts added yet. Discover some here." with a link to the DiscoverScreen). I should be able to pull-to-refresh the LibraryScreen, PodcastDetailScreen, and DiscoverScreen. The app should read the device's light/dark mode setting on launch and update automatically if the user changes it while the app is open. I should also be able to toggle the light or dark mode from within the app to override my device settings if I want.

On tablet, all features should work identically to phone. The layout should adapt to take advantage of the larger screen, using two-column layouts where it makes sense, larger artwork, and slightly larger text. Both phone and tablet should support portrait and landscape orientations.
